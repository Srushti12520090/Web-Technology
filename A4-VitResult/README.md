# VIT Semester Result Calculator

React + Vite responsive semester result website.

## Features
- Student information
- Four subjects
- MSE marks (30%)
- ESE marks (70%)
- Final marks calculation
- Grade calculation
- Total marks
- Percentage
- SGPA
- Pass/Fail status
- Responsive design

## Run

```bash
npm install
npm run dev
```

Then open the localhost URL shown by Vite.
