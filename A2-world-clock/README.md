# Chronos - Real-Time World Clock Dashboard

React + Vite project featuring:
- Analog clock
- Digital clock
- Multiple time zones
- Dynamic time-zone management
- Alarm center
- Dark/light mode
- 12/24 hour format
- Responsive UI
- Live animations

## Run

```bash
npm install
npm run dev
```

Open the URL shown by Vite, usually http://localhost:5173/
