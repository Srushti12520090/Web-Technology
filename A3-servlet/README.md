# Electricity Bill Calculator - Servlet + JSP

## Requirements
- JDK 11+
- Apache Tomcat 10+
- Eclipse/IntelliJ/NetBeans or another Java web IDE

## Rates
- First 50 units: Rs. 3.50/unit
- Next 100 units: Rs. 4.00/unit
- Next 100 units: Rs. 5.20/unit
- Above 250 units: Rs. 6.50/unit

## Run
Import as a Dynamic Web Project or Maven-style web project in your IDE.
Deploy to Tomcat 10+ and open:
http://localhost:8080/ElectricityBillServletJSP/
